# EBAC-Backend

## Description

This repository contains the backend implementation for the EBAC project. It is designed using Java and serves as an essential part of the backend system.

## Features

- Backend API for handling business logic
- Integration with databases
- Provides RESTful services

## Requirements

- Java 11 or higher
- Maven for project management
- Any relevant dependencies installed

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Bianca-Ribeiro-0/EBAC-Backend.git

2. Navigate into the project directory:

cd EBAC-Backend

Build the project using Maven:

mvn clean install

3. Run the application:

mvn spring-boot:run

## Usage

Once the application is up and running, you can access the API endpoints.
